How this sim counts significant figures

Significant figures are a claim about how well something was measured. Two numbers can be the same amount and still make different claims — which is why how you write your answer matters here.

The same amount, written five ways

You writeSig figsWhy
650002No decimal point, so the zeros are only holding the place. You measured "65 thousand-ish".
65000.5The decimal point promotes every zero in front of it. You measured all five digits.
65000.06Five, plus one more measured digit after the point.
6.5 × 10⁴2Only the front part counts. Same value as 65000, same claim.
6.500 × 10⁴4Same value again, now claiming four measured digits.

Where students get caught: one hundred

You writeSig figsWhy
1001Bare, with no decimal point, this claims a single measured digit.
100.3The decimal point promotes both zeros.
1 × 10²1Unambiguous: one measured digit.
1.0 × 10²2Unambiguous: two.
1.00 × 10²3Unambiguous: three.

All five are the same amount. They are not the same statement about your measurement. If you need two sig figs, 100 will be marked down and 1.0 × 10² will not.

The rules in full

  1. Every non-zero digit counts.
  2. Zeros between non-zero digits count — 4005 has four.
  3. Leading zeros never count. They only place the decimal.
  4. Trailing zeros count only if a decimal point is present.
  5. Scientific notation removes the guesswork: write exactly the digits you mean.
