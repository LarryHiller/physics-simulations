How the projected AP score works

Each set keeps its own score. Once you've answered 5 questions in a set, your percent correct is turned into a projected AP score using the typical curve on the AP Physics exam:

AP scorePercent correct
565 – 100%

1below 26%

The projection is only as good as the number of questions behind it. After 5 questions one answer moves you 20 points; after 40 it moves you about 2. Every question counts on the first try only, so think before you check.
