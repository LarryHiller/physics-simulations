Dot & cross rules for î, ĵ, k̂

Dot product

î · î = 1î · ĵ = 0
ĵ · ĵ = 1ĵ · k̂ = 0
k̂ · k̂ = 1k̂ · î = 0

A parallel unit vector dotted with itself gives 1; any two different (perpendicular) unit vectors dot to 0.

A · B = AxBx + AyBy + AzBz = |A||B|cos θ

Cross product

î × î = 0
ĵ × ĵ = 0
k̂ × k̂ = 0

Any unit vector crossed with itself is 0. For two different ones, go in the cycle î → ĵ → k̂ → î:

î × ĵ = +k̂ĵ × î = −k̂
ĵ × k̂ = +îk̂ × ĵ = −î
k̂ × î = +ĵî × k̂ = −ĵ

Forward through the cycle ("ijki") is positive; backward ("ikji") is negative.

|A × B| = |A||B|sin θ, with direction perpendicular to the plane of A and B by the right-hand rule — for two vectors in the xy-plane, that direction is always straight along z: out of the page for a positive result, into the page for a negative one.
